# Piero reel edit skill

Claude skill that edits Piero's raw talking-head videos into his signature reel format.

## Setup (once)
1. In Claude settings, turn on code execution and file creation.
2. Download `piero-reel-edit.zip` from this repo (don't unzip it).
3. Upload it as a custom skill in Claude (Settings > Capabilities > Skills), then make sure it's enabled.

## Use
New chat, drag in the raw clip, the collage background image and Piero's script text if you have it, then say "edit this".

## Updates
When the format changes, the new zip lands here. Delete the old skill in Claude and upload the new one.
